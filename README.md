# Giovanna Tirado Olivera - A01068247

**Juego:** Tic Tac Toe (Gato)

**Rama:** `A01068247_tictactoe`

**Cambios realizados:**
1. **Símbolos X y O:** se cambió su tamaño y color (X roja, O azul, línea más gruesa) y se centraron dentro de cada casilla.
2. **Validación de casillas:** si se hace clic en una casilla ocupada no se dibuja nada, no cambia el turno y se muestra un aviso en la terminal. También se ignoran los clics fuera del tablero.
3. **Fin del juego:** después de cada tiro se revisan filas, columnas y diagonales; se muestra en pantalla quién ganó o si hubo empate, y ya no se permiten más tiros.

**Cómo ejecutarlo:**
python3 tictactoe.py
